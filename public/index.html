Cấu hình Node

ID và Node Address là riêng từng node. Gateway Address và các thông số Network ID, Channel, Baud code, Air rate, Power là profile mạng dùng chung. Profile LoRa được lưu/stage trước để tránh node đổi sóng trước gateway. Mỗi node có UID riêng lưu trong EEPROM; gateway dùng UID để phân biệt node ngay cả khi ID mặc định bị trùng sau lần nạp đầu. Khi kích hoạt LoRa, node sẽ tự rollback về cấu hình cũ nếu không nhận được Commit trong 60 giây. Trước khi Commit, gateway Raspberry Pi cũng phải được cấu hình sang cùng profile mới, nếu không gateway sẽ không thấy node trên mạng mới.
